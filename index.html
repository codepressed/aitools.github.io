About this Repository

This is a static, GitHub Pages–friendly site. Content lives in the repo. Videos can be embedded from YouTube/Vimeo or GitHub assets. Progress is stored locally for simplicity, and a backend can be added later for account-based tracking and public verification links.

  • Frontend: Tailwind via CDN.
  • Progress: localStorage (upgrade-ready for Supabase/Auth0+Cloud Run).
  • Certificate: client-side using jsPDF. Optional QR can point to a future verify endpoint.
